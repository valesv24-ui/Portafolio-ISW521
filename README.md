# Portafolio ISW-521 — Programación en Ambiente Web I

Este repositorio reúne las actividades, ejercicios y proyectos realizados durante el curso **ISW-521: Programación en Ambiente Web I**, de la carrera de Ingeniería en Software (UTN, Sede San Carlos).

## Contenido destacado

- **Landing Page - Amaretto's Café**: proyecto de laboratorio con maquetación en HTML/CSS/JS.
- **Ejercicios de JavaScript**: fundamentos, operadores, programación orientada a objetos (clases `Animal`, `Perro`).
- **Mini proyectos web**: combinaciones de HTML, CSS y JS.
- **Proyecto en React** (`mi-proyecto`): aplicación base creada con React.
- **whatsapp-chat-hex**: proyecto con integración de WhatsApp Web (Node.js/TypeScript).
- **Proyecto en TypeScript**: ejercicios de tipado y configuración de TS.
- Actividades teóricas entregadas en formato Word (`.docx`) y texto plano (`.txt`).

## Tecnologías utilizadas

- HTML5, CSS3, JavaScript
- TypeScript
- React
- Node.js
